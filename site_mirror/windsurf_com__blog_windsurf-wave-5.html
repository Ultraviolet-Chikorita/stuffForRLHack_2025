Page: https://windsurf.com/blog/windsurf-wave-5

Summary

This is a blog post announcing Windsurf Wave 5, which introduces a new feature called "Windsurf Tab" - a passive predictive AI system that captures fine-grained user actions across the editor, terminal, and clipboard. The post explains how this feature builds on their existing Cascade technology and positions Windsurf as an AI-powered code editor suitable for both professional developers and non-developers. Visitors can read about the technical details of the new feature, understand the company's product philosophy, and access download options at the bottom of the page.
