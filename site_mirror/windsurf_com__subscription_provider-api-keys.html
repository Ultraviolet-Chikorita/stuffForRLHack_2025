Page: https://windsurf.com/subscription/provider-api-keys

Summary

This is a settings page within the Windsurf platform where users can manage their API keys for third-party model providers. Visitors can view and input their Anthropic API key which will be used to power Cloud models in the service, with the ability to save their key and access additional management options through the Anthropic console. The page is part of a larger account management section that includes other options like Profile, Notifications, Usage, and subscription management.
