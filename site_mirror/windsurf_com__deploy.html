Page: https://windsurf.com/deploy

Summary

This is the App Deploys page within a Windsurf user account dashboard, currently in beta. The page allows users to view and manage their deployed applications, though the current user has no existing deployed apps yet. A typical visitor can learn how to deploy their first app through the provided link, and access various account management features through the left sidebar including profile settings, usage monitoring, plan management, and API configuration.
