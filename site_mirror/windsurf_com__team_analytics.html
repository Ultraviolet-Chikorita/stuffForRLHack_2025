Page: https://windsurf.com/team/analytics

Summary

This is a Windsurf analytics dashboard page showing usage statistics and metrics for a specific user account. The page displays core analytics including code writing percentages, active users, lines of code written, Cascade messages sent, tool calls, model usage, and other development-related metrics over a specified time period. Users can view their account activity, manage their subscription settings, track usage across different products and teams, and monitor various development metrics like tab acceptances by programming language and conversation statistics.
